# NFT Gallery Website

## Overview

NFT Gallery Website is a responsive web application that allows users to browse and explore NFT collections in a visually appealing gallery interface.

The project focuses on frontend development, digital asset presentation, and responsive UI design.

## Features

* NFT gallery display
* Search functionality
* Responsive layout
* Modern user interface
* Digital artwork showcase

## Technologies Used

* HTML
* CSS
* JavaScript

## Run Project

Open index.html in your browser.
